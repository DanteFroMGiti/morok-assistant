# Character pack contract v1

Каждый персонаж хранится в отдельной папке и содержит `character.json` и PNG-атлас
с прозрачным фоном. Размеры атласа не зашиты в движок.

Обязательные поля:

- `id` — стабильный уникальный идентификатор;
- `name` — отображаемое имя;
- `sprite` — локальный путь к атласу внутри пакета;
- `frame` — ширина и высота одной ячейки;
- `grid` — число столбцов и строк;
- `animations.idle` — обязательное состояние покоя.

Каждая анимация содержит явный список координат `[column, row]`, благодаря чему
кадры могут лежать в любой части атласа и повторяться. `loop: false` завершает
одноразовое действие и включает `fallback`.

Точка `anchor` резервируется для будущего позиционирования ног персонажа при ходьбе,
прыжках и смене атласа. Масштаб должен быть целым, чтобы пиксельная графика оставалась
чёткой.
