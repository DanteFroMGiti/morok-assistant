# Morok Assistant

Первый модульный прототип экранного помощника для Linux. Сейчас он умеет показывать
анимированного Морока в прозрачном окне, переключать состояния и перетаскиваться по
рабочему столу. Через 30 секунд бездействия Морок садится и ждёт; при взаимодействии
встаёт. Если во всей системе нет действий около минуты, он уходит за край экрана и
выглядывает из случайных мест, увеличивая голову. В случайные моменты он следит
глазами за курсором и показывает анекдоты.
Через настройки Морока можно подключить OpenAI и общаться с выбранной моделью текстом.
Архитектура заранее отделяет персонажей, анимацию, интерфейс и будущие
системные плагины.

## Установка

На Linux Морок устанавливается без прав администратора:

```bash
git clone https://github.com/DanteFroMGiti/morok-assistant.git
cd morok-assistant
./install.sh
```

Установщик создаёт отдельное окружение в `~/.local/share/morok-assistant`, команду
`~/.local/bin/morok-assistant` и ярлык в меню приложений. Для удаления запустите
`morok-assistant-uninstall`. Настройки сохранятся; команда
`morok-assistant-uninstall --purge` удалит и их.

## Запуск из исходного кода на CachyOS

```bash
cd morok-assistant
python -m venv .venv
source .venv/bin/activate
pip install -e ".[dev]"
python -m morok_assistant
```

Либо после установки:

```bash
morok-assistant
```

Для запуска из корня проекта можно дважды нажать исполняемый файл `run-morok.sh`.
После установки Морок также появляется в меню приложений и не запускает вторую копию,
если уже работает. В «Настройки… → Поведение» можно включить запуск при входе в
систему; ярлык создаётся в `~/.config/autostart/`.

Управление:

- левая кнопка мыши — перетащить Морока;
- двойной щелчок — помахать;
- правая кнопка — открыть настройки и диалог с ИИ, выбрать анимацию, сбросить позицию
  или выйти;
- в меню «Масштаб» доступны ×0,5, ×1, ×2 и ×3;
- «Рассказать анекдот» в меню — проверить анекдоты сразу;
- «Поговорить с ИИ» — открыть текстовый диалог; «Настройки…» — выбрать модель и ключ;
- «Выглянуть сейчас» — короткий показ ухода и выглядывания;
- «Таймеры и напоминания…» — создать таймер или напоминание на конкретную дату;
- «Режим концентрации…» — рабочий интервал с паузой и напоминанием об отдыхе;
- «Команды и поиск…» — найти и запустить установленную программу или открыть файл;
- «Разобрать код или ошибку из буфера» — подготовить вопрос выбранной модели ИИ;
- `Esc` — закрыть приложение.

Ожидание команды пока визуальное: команды для управления компьютером появятся отдельно.
После короткой паузы Морок начинает следить глазами за указателем и продолжает до
клика по нему или до истечения двух минут. Через три минуты без взаимодействия с
самим Мороком он сворачивается и засыпает. Во сне он не рассказывает анекдоты и не
выглядывает автоматически; движение мыши в других окнах его не будит. Клик по нему
или действие в его меню будит Морока. При перетаскивании он поднимает лапу и держит
её у указателя; простой клик не сдвигает персонажа.

В «Настройках…» можно выбрать OpenAI (GPT), Anthropic (Claude), Google (Gemini),
DeepSeek, OpenRouter (в том числе Llama), локальный Ollama или другой API,
совместимый с Chat Completions. Для облачного сервиса нужен его собственный ключ;
ключи и выбранные модели сохраняются отдельно, поэтому переключение сервиса не
стирает прежний ключ. ID модели можно ввести вручную. Для совместимого API нужно
указать полный адрес конечной точки, например
`http://127.0.0.1:1234/v1/chat/completions`. Настройки хранятся в
`~/.config/morok-assistant/ai.json` (или в `$XDG_CONFIG_HOME/morok-assistant/ai.json`)
с доступом только для владельца. Ключ можно также задать переменной окружения,
указанной в окне выбранного сервиса.

Для Ollama ключ не нужен. В настройках нажмите «Запустить Ollama», если сервер
выключен; установленные модели появятся в списке. Если моделей нет, установите
одну командой `ollama pull llama3.2` и обновите список. Диалог показывает ответ
и в переписке, и в текстовой
реплике над Мороком. Кнопка «Новый диалог» сбрасывает контекст; при смене сервиса
или модели диалог тоже начинается заново. OpenAI использует Responses API, прочие
сервисы получают историю открытого диалога в каждом запросе. Морок отправляет
запрос только после нажатия «Отправить» и во время переписки не прерывает её
случайными анекдотами и выглядыванием. Голосовое общение появится отдельно.

В тех же настройках можно выбрать, что делает двойной клик по Мороку и как он
реагирует на наведение мыши. По умолчанию двойной клик вызывает взмах лапой, а
наведение — наблюдение за курсором. Наведение срабатывает после 0,6 секунды и не
повторяет действие чаще одного раза в 8 секунд. Выбор жестов сохраняется в
`~/.config/morok-assistant/gestures.json`.

Таймеры и напоминания сохраняются в `~/.config/morok-assistant/reminders.json`, поэтому
не пропадают после перезапуска. Во время концентрации Морок сидит спокойно, не
рассказывает случайные анекдоты, не выглядывает и не уходит смотреть видео. После
рабочего интервала он сообщает о перерыве и затем зовёт вернуться к работе.

При обычном напоминании Морок увеличивается до масштаба ×2 и машет. Если его не
коснуться, через 8 секунд он бежит к указателю. Добравшись, Морок удерживает указатель
на месте и отпускает его после нажатия `Enter`, затем возвращает прежний масштаб.

На вкладке «Запуск программ» в настройках можно выбрать установленные приложения,
которые должны открываться вместе с Мороком. Каждый пункт можно временно отключить,
не удаляя его из списка. Выбор хранится в
`~/.config/morok-assistant/startup-apps.json`.

Локальные команды не отправляются в ИИ. Приложения читаются из системных файлов
`.desktop`, а файлы ищутся по имени в домашней папке. В разделе «Поведение» можно
отдельно отключить реакции на игры, музыку, редакторы кода и долгую работу с
документами. Во время игры Морок не отвлекает; рядом с музыкальным проигрывателем
он садится и двигает хвостом; в редакторе замечает скопированный текст ошибки; после
45 минут непрерывной работы с документом предлагает сделать перерыв.

Если включено «Садиться у окна с видео и смотреть вместе», Морок проверяет активное
окно и плавающие окна «Картинка в картинке» в X11. Он узнаёт отдельные проигрыватели
(VLC, mpv, Celluloid и другие), популярные
видеосайты по заголовку вкладки и полноэкранное воспроизведение со звуком. После
обнаружения он проверяет свободное место слева, справа, сверху и снизу. Среди всех
подходящих сторон место выбирается случайно. Сбоку Морок повёрнут к окну спиной в три
четверти и смотрит на видео через плечо; снизу он смотрит вверх, сверху сидит передом
и смотрит вниз. Он не закрывает изображение и плавно следует за окном при его
перемещении. Если места недостаточно со всех сторон, Морок остаётся на месте.
Морока можно перетащить к нужной стороне видео вручную: после отпускания он выберет
ближайшую допустимую позицию и продолжит смотреть оттуда. Если отпустить его далеко
от окна, автоматическое возвращение к этому видео отменяется.
После закрытия или переключения с видео возвращается на прежнее место. Клик и ручное
перетаскивание отменяют просмотр до следующего видео, поэтому Морок не спорит с
пользователем за позицию. Эта функция зависит от X11; в сеансе Wayland она отключается.
Если OpenAI вернёт `credit_balance_exhausted` (429), у аккаунта закончились кредиты
API. В настройках Морока есть ссылка «Баланс API» для проверки и пополнения; повторять
запрос до пополнения не нужно.

Анекдоты показываются только текстом. Они добавляются в `jokes.txt` рядом с `README.md`:
один анекдот на блок. Между блоками можно поставить пустую строку или строку из трёх
и более длинных тире (`———`). Если в файле есть строки из тире, пустые строки внутри
анекдота сохраняются. Несколько строк внутри блока допустимы, строки с `#` — комментарии.
Файл перечитывается перед каждым рассказом, поэтому перезапуск не нужен. Случайный
анекдот появляется примерно раз в 3–7 минут. Если приложение установлено без исходного
проекта, файл создаётся в `~/.config/morok-assistant/jokes.txt`.

Автоматический уход за экран начинается после 60 секунд без движений мыши и нажатий
клавиш в сеансе X11, когда Морок не наблюдает за указателем и не спит. Если
PulseAudio/PipeWire сообщает об активном воспроизведении или записи звука,
Морок остаётся на месте. Движение мыши, клавиша или щелчок по выглядывающей голове
возвращают его к прежней позиции.
При выглядывании рога появляются первыми: рисунок поворачивается к выбранному краю,
а окно открывает только видимую часть головы.
Если Морока долго не трогали во время выглядывания, он возвращается на своё место и
засыпает.

Исходные кадры сидения и взгляда хранятся в `art/`. Для пересборки атласа после их
обновления:

```bash
pip install -e ".[art]"
python tools/build_sitting_atlas.py
python tools/build_behavior_atlas.py
```

## Границы модулей

```text
core/          независимые модели, события и ошибки
animation/     загрузка манифеста и машина состояний анимации
ai/            настройки и сетевое подключение к выбранной модели
characters/    обнаружение и выбор пакетов персонажей
ui/            только отображение и пользовательский ввод
plugins/       контракт будущих функций и их разрешений
system/        чтение активности рабочего стола
application/   сборка зависимостей и запуск приложения
```

Новый персонаж добавляется папкой с `character.json` и PNG-атласом. Код приложения
менять не требуется. Формат описан в `docs/character-packs.md`.

## Следующая ветка развития

1. Менеджер персонажей и общие настройки внешнего вида.
2. Хранение позиции и выбранного персонажа.
3. Событийная шина между интерфейсом и плагинами.
4. Безопасные системные плагины: звук, приложения, мониторинг.
5. Другие ИИ-сервисы, локальные модели и голос как отдельные адаптеры.
